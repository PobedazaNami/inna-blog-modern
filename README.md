# Современная версия — отдельная копия

Публичный предпросмотр: https://pobedazanami.github.io/inna-blog-modern/

GitHub Pages публикует папку `docs/` из ветки `codex/preview`. Для обновления после `npm run build` скопировать содержимое `dist/` в `docs/`, закоммитить и отправить изменения.

Исходники нового варианта находятся в `modern/`. `copy/`, `redesign/` и `original/` не изменялись при разработке этого варианта.

Стек: React, TypeScript, Vite, Tailwind CSS, Motion. Шрифт Manrope размещён локально; изображения WebP. Реализованы анимированные вкладки четырёх дней, объёмная схема, эффект глубины портрета при движении мыши, интерактивные отзывы с увеличением, FAQ, мобильное меню и фиксированная кнопка. Учитывается reduced motion. Полоса прогресса прокрутки работает через CSS Scroll-driven Animations в поддерживающих браузерах.

В разделе «Про мене» установлено фото, присланное пользователем 22 октября: `public/images/author-new.webp` (960×1280, 68 712 байт). Предыдущий портрет в этом варианте заменён.

## Запуск и сборка

`npm ci --legacy-peer-deps` — установить зависимости по lock-файлу.

`npm run dev` — разработка.

`npm run build` — проверка TypeScript, сборка Vite и предварительный рендер HTML. Готовый статический сайт в `dist/`. Все тексты находятся в HTML до запуска React; интерактивный код загружается после первого отображения. Ранний клик по кнопке сохраняется до завершения гидратации.

Сайт опубликован на GitHub Pages отдельной копией. При необходимости переноса на Vercel: команда сборки `npm run build`, выходная папка `dist`. Оригинальный проект Vercel не изменён.

Локальный просмотр через уже запущенный сервер: http://127.0.0.1:8039/modern/dist/ . Эта ссылка доступна только на данном ПК.

## Проверка

`verify.py` сверяет текст клиента в предварительно отрендеренном HTML, программу четырёх дней, данные шести отзывов и локальные изображения. Проверены вкладки, FAQ и просмотр отзыва в браузере; TypeScript и производственная сборка проходят.

Последний полный Lighthouse перед заменой фото в нижнем блоке: телефон — 97 / 100 / 100 / 100; ПК — 100 / 100 / 100 / 100 (Performance / Accessibility / Best Practices / SEO). Замеры для localhost. Для опубликованной HTTPS-копии нужен отдельный Google PageSpeed Insights. Отчёты `modern-mobile.report.html` и `modern-desktop.report.html` находятся в родительской папке.

Платёжная система, оферта и политика не подключены: исходный сайт содержал заглушки. Основные кнопки в этом варианте честно ведут к программе; перед началом продаж нужно добавить согласованную ссылку на оплату.

Клиентские тексты: `src/content.json`; компоненты: `src/App.tsx`; оформление: `src/styles.css`.
